# my-ui

React UIs built on [Base UI](https://base-ui.com), each with its own look. Not on npm yet.

- **Inter-Knot** (绳网): black dotted bars and breathing yellow plates.
- **Ghostly Grove** (罗浮杂俎): dark teal frames with a cyan glow.
- **Furbobo Gossip** (狸狸通信): orange and paper, ink outlines.
- **PRTS** (普瑞赛斯): steel plates and blue selection.

```bash
pnpm install
pnpm dev   # http://localhost:5173/
```
